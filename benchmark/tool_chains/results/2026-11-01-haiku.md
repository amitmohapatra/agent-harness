distractors), one run per case and arm. The memory arms ran on a private memory service with no
worker: its learning job was run every 20 seconds from outside, as the worker runs it every five
minutes. The *full stack* has every model; the machine ran short of memory, so the later memory
arms ran on a *lean stack* (the NLI model replaced by its lexical stand-in, the multilingual
encoder off). The lean stack's tool hints never reached the narrowing floor until a learned
skill named the tools, so compare memory arms within one stack. *memory main* is the memory
service on main; *memory fix* has the verdict-projection fix (a confirm citing ten or more
memories was never projected, so it taught nothing). Code Mode was not measured: it needs the
Bifrost gateway.
